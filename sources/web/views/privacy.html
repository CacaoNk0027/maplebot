Política de privacidad

Qué información utiliza Maple, para qué la necesita y qué opciones tienes sobre ella.

Última actualización: 12 de agosto de 2026

Esta política se aplica al bot Maple en Discord, a esta web y a sus funciones asociadas. Discord procesa información por separado conforme a su propia política.

1. Responsable y alcance

El equipo de Maple administra el tratamiento descrito en esta política. Puedes contactarlo mediante el servidor de soporte indicado al final. Al utilizar Maple se tratarán los datos técnicamente necesarios para responder a tus solicitudes y mantener las configuraciones elegidas.

2. Información que podemos tratar

Datos procedentes de Discord

  • Identificadores de usuario, servidor, canal, rol y mensaje.
  • Nombre de usuario, avatar, nombre e icono del servidor y otra información pública entregada por la API de Discord.
  • Permisos y relaciones necesarias para comprobar si una persona puede ejecutar o configurar una función.

Datos de uso y configuración

  • Prefijo e idioma del servidor cuando estas opciones estén disponibles.
  • Canales, roles y ajustes escogidos por quienes administran el servidor.
  • Textos, colores, fondos y enlaces configurados para bienvenidas y despedidas.
  • Identificador de usuario, nivel y experiencia para funciones de progresión.

Datos de la web

  • Nombre de usuario y contraseña protegida mediante hash si utilizas el sistema de cuenta web existente.
  • Identificadores internos, tokens almacenados mediante hash, cookies de sesión y fechas técnicas asociadas.
  • Información básica de solicitudes que pueda ser registrada por el alojamiento para seguridad y diagnóstico, como dirección IP, agente de usuario y fecha.

Maple no solicita contraseñas de Discord, tokens de cuenta ni información de pago mediante comandos.

3. Para qué utilizamos la información

  • Ejecutar comandos y entregar respuestas solicitadas.
  • Guardar configuraciones para que continúen funcionando en el servidor.
  • Generar bienvenidas, despedidas, imágenes y otras funciones personalizadas.
  • Gestionar sesiones y proteger el acceso a las funciones web.
  • Prevenir abuso, investigar fallos y mantener la seguridad y estabilidad de Maple.
  • Cumplir obligaciones legales válidas y las políticas aplicables de Discord.

4. Contenido de mensajes

Maple puede recibir y procesar el contenido de mensajes cuando es necesario para detectar comandos tradicionales por prefijo, moderar o ejecutar una función expresamente utilizada. Las interacciones slash entregan a Maple las opciones enviadas mediante Discord.

No declaramos que todo mensaje visible para Maple se almacene permanentemente. Algunos contenidos sí se guardan cuando forman parte de una configuración, como un texto de bienvenida o despedida. Evita introducir datos sensibles en comandos o configuraciones.

5. Servicios y terceros

Maple depende de servicios que pueden tratar datos para prestar su parte del servicio:

  • Discord, como plataforma en la que opera el bot.
  • Proveedores de alojamiento, red y base de datos utilizados para ejecutar Maple y almacenar su configuración.
  • Servicios enlazados voluntariamente desde la web, que aplican sus propias políticas cuando los visitas.

No vendemos información personal. Podemos comunicar información cuando sea necesario para prestar el servicio, proteger derechos y seguridad o responder a una obligación legal válida.

6. Conservación y eliminación

Conservamos configuraciones mientras Maple siga presente o la función continúe activa, y datos de cuenta mientras exista la cuenta o sean necesarios para seguridad. Los periodos exactos pueden variar según el tipo de dato y las copias de seguridad.

Retirar Maple de un servidor no garantiza la eliminación inmediata de toda configuración. Un administrador o la persona afectada puede solicitar eliminación mediante soporte. Podremos conservar información mínima cuando sea necesaria para prevenir abuso, resolver disputas o cumplir obligaciones legales.

7. Seguridad

Aplicamos medidas razonables como hashes para contraseñas y tokens, cookies de sesión HTTP-only y controles de permisos. Ningún sistema conectado a internet es completamente seguro, por lo que no podemos garantizar seguridad absoluta. Nunca compartas credenciales mediante comandos o mensajes de soporte públicos.

8. Acceso, corrección y eliminación

Puedes solicitar información sobre los datos asociados a tu cuenta, corregirlos o pedir su eliminación. Para datos pertenecientes a la configuración de un servidor podremos pedir que demuestres que eres propietario o administrador autorizado. También puedes dejar de utilizar Maple, retirarla del servidor o eliminar sus configuraciones disponibles.

La disponibilidad de derechos adicionales depende de las leyes de tu ubicación.

9. Cambios en esta política

Actualizaremos esta política cuando cambien las funciones, las prácticas de datos o los requisitos aplicables. Indicaremos la fecha de la revisión más reciente y podremos anunciar modificaciones importantes en la web o el servidor de soporte.

10. Contacto

Para solicitudes de privacidad, eliminación de datos o reportes de seguridad, contacta al equipo mediante el servidor de soporte de Maple. No publiques datos sensibles en canales visibles para otras personas.

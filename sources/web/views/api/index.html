Empezar

Tres pasos y tu bot ya responde con GIFs.

  1. Crea una cuenta

    Solo pide un nombre de usuario y una contraseña. No necesitas vincular Discord.

  2. Genera tu token

    Desde tu cuenta. Se muestra una sola vez, así que guárdalo en las variables de entorno de tu bot.

  3. Pide GIFs

    Con cualquier cliente HTTP, o con el paquete neekuro si tu bot usa Node.js.

Referencia

Endpoints

Todas las rutas responden JSON con la misma forma: message, code y data.

URL base

<%= baseUrl %>

Autenticación

Envía tu token en la cabecera Authorization de cada petición. El prefijo Bearer es opcional.

Authorization: Bearer TU_TOKEN

Rutas

{tipo} es action o reaction, y {categoría} cualquiera de la lista de categorías.

Método Ruta Devuelve
GET /api/sfw Las rutas de los dos tipos.
GET /api/sfw/{tipo} El catálogo completo del tipo, con todas sus categorías.
GET /api/sfw/{tipo}/{categoría} Todos los GIFs de la categoría.
GET /api/sfw/{tipo}/{categoría}?random=true Un GIF al azar de la categoría.

Cada GIF trae su url, el anime del que viene y un _id.

Errores

Código Significa
401 Falta la cabecera Authorization.
403 El token no es válido, o se regeneró y ya no está vigente.
404 La categoría no existe o todavía no tiene GIFs.
500 Error del servidor. Vuelve a intentarlo en unos minutos.

Ten en cuenta

  • Al regenerar el token, el anterior deja de funcionar al instante.
  • El catálogo se refresca cada 5 minutos: un GIF recién añadido puede tardar ese tiempo en aparecer.
  • Es un servicio gratuito. Si tu bot depende de él, maneja los errores para que una caída no lo detenga.

Para Node.js

El paquete neekuro

Hace las peticiones por ti, trae los tipos de TypeScript y guarda cada lista 5 minutos para ahorrar llamadas, sin repetir el mismo GIF dos veces seguidas.

Ver en npm →
Terminal 
npm install neekuro
bot.js 
const neekuro = require('neekuro')

// El token se fija una vez para todo el paquete.
new neekuro.User(process.env.NEEKURO_TOKEN)

async function abrazo() {
    const gif = await neekuro.SFW.getGif('action', 'hug')
    console.log(gif.getUrl(), gif.getAnime())
}

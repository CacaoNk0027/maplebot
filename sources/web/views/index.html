Nuestra historia

Maple nació para hacer Discord un poco más cercano.

El proyecto comenzó el 16 de marzo de 2021 con una idea sencilla: ayudar a comunidades nuevas a construir un espacio bonito, organizado y fácil de disfrutar.

Hoy Maple sigue creciendo con ese mismo propósito. Cada actualización busca ahorrar trabajo a quienes administran servidores y crear mejores momentos para quienes los habitan.
